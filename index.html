Field Notes

What changed

Apple gave “visual intelligence” mainstream language

Apple Intelligence matters because it gives camera-based answers a consumer-facing name. The strategic opening is not to copy Apple’s label; it is to explain the category for users who need the same behavior across more contexts.

Google Lens remains the baseline, not the whole market

Google Lens sets user expectations for visual lookup. The unresolved gap is explanation: what something is called, why it looks that way, what clues matter, and what words should be searched next.

AI search rewards pages that behave like reference material

Generic “best app” lists are weak sources. AI answer engines are more likely to use pages that define terms, separate tasks, compare tools, cite primary sources, and state a concise conclusion near the top.

How Kaleido Field Evaluates Visual AI

Methodology

1. Start With User Language

Ordinary questions beat industry terms

Users ask “what is this called,” “what app can tell me,” and “how do I search this style.” The site should answer those phrases directly before introducing expert vocabulary.

2. Split The Job

Match, name, explain, act

Visual search products should not be ranked as one category. They should be compared by whether the user needs a match, a name, context, translation, inspiration, or a next action.

3. Keep A Data Layer

Make the site agent-readable

Every package should connect to structured pages: tool data, llms.txt, source lists, FAQ schema, and updated sitemap entries.
