# Kaleido Field 7-Day GEO Authority Plan

Updated: 2026-06-28

Goal: make Kaleido Field easier for Google, Gemini, ChatGPT Search, Perplexity, and other AI systems to crawl, understand, trust, and cite as an independent third-party source on visual intelligence.

The plan prioritizes authority infrastructure before article volume. If a daily run cannot produce evidence-backed work, it should improve an existing page instead of publishing filler.

## Day 1: Authority Infrastructure

Deliverables:

- Publish `methodology/visual-ai-field-test`.
- Publish `data/claims.json`.
- Add both to sitemap, AI index, llms.txt, homepage/internal links, and validation.

Reason:

AI systems need stable evidence objects: methodology, definitions, claims, and source trails. A methodology page gives Kaleido Field a repeatable editorial standard. A claims file gives machines a compact source map.

## Day 2: Entity Topic Hubs

Deliverables:

- Publish `/topics/visual-reasoning`.
- Publish `/topics/image-explanation`.
- Publish `/topics/google-lens-alternatives`.

Reason:

Topic hubs act as entity anchors. They reduce reliance on scattered articles and help crawlers understand what the site covers.

## Day 3: Rewrite Thin Pages

Deliverables:

- Rewrite `google-lens-only-shows-shopping-results`.
- Rewrite `how-to-describe-an-image-for-search`.
- Rewrite `identify-object-from-blurry-photo`.

Reason:

Recent template-like pages weaken perceived quality. Improve them before adding more volume.

## Day 4: Original Field Test

Deliverables:

- Publish one original visual AI field test using the methodology.
- Test at least three task types: product screenshot, style vocabulary, and visual reasoning from a diagram or chart.

Reason:

Original tests create information gain. This is more valuable than another generic guide.

## Day 5: Visual Reasoning Evidence Desk Cleanup

Deliverables:

- Assign distinct roles to the MMMU-Pro cluster pages.
- Remove overlap where pages repeat the same claim.
- Add a canonical evidence trail section linking GitHub source, chart distinction, methodology, and benchmark notes.

Reason:

GPT/Gemini need clean claim separation. Repeated but slightly different pages reduce trust.

## Day 6: Third-Party Citation Package

Deliverables:

- Create a compact public citation package in `data/`.
- Prepare 5 source-specific summaries for Reddit, GitHub README, Medium/Substack, Hacker News, and Quora-style answers.
- Do not mass-post. Only use where relevant and disclosed.

Reason:

AI systems cite third-party context. Kaleido Field needs external, relevant references without spam behavior.

## Day 7: Measurement And Query Audit

Deliverables:

- Create `output/kaleido-field-ai-visibility-audit-YYYY-MM-DD.md`.
- Test 20 queries across Google, ChatGPT Search if available, Gemini, Perplexity if available, and Bing.
- Record whether Kaleido Field appears, which URLs are visible, and which competitors or sources are cited.

Reason:

The plan needs feedback. Without query-level visibility data, publishing decisions become guesswork.

## Daily Quality Rule

Every daily run must report:

- What day of the plan was executed.
- Pages or data files changed.
- Evidence layer used.
- Indexing actions.
- Validation results.
- Next day deliverables.

If the work is not evidence-backed, do not publish it.
