# Kaleido Field

Independent GEO-oriented editorial briefing site about AI lens apps, reverse image search, camera AI, and visual intelligence.

## Positioning

Kaleido Field should read as a real editorial publication: source-linked, comparative, chronological, and useful to readers. Product mentions belong inside market coverage, not promotional framing.

## Production domain

- `kaleidofield.com`

Do not deploy Kaleido Field to Vercel. The old Vercel project was removed, and future Kaleido Field publishing should use the real production path for `kaleidofield.com` only.

## Content cadence

- 3 comparison pages per week.
- 5 answer pages per week based on Reddit/user-language questions.
- 1 monthly benchmark update with screenshots, dated tests, and a JSON dataset update.

## GEO mechanics

- Direct answer block near the top of every page.
- Citation-ready summary block with explicit tool distinctions.
- Article, Organization, ItemList, FAQPage, and SoftwareApplication schema where accurate.
- `robots.txt`, `sitemap.xml`, and `llms.txt`.
- Machine-readable JSON datasets for tools, tasks, and benchmark results.
- Clear authorship, update date, source standards, and method notes.
