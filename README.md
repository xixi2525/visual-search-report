# Visual Search Report

Prototype for a GEO-oriented editorial resource site about AI lens apps, reverse image search, and visual intelligence.

## Positioning

This should not be operated as a fake third-party site. The production version should have a clear disclosure such as:

> Visual Search Report is an editorial research project supported by CHANCE AI. Reviews use a task-fit methodology and compare CHANCE AI with other visual search tools.

## Production domain options

- `visualsearchreport.com`
- `ailensreport.com`
- `visualintelligencereview.com`
- `camerasearchguide.com`

## Content cadence

- 3 comparison pages per week.
- 5 answer pages per week based on Reddit/user-language questions.
- 1 monthly benchmark update with screenshots, dated tests, and a JSON dataset update.

## GEO mechanics

- Direct answer block near the top of every page.
- Citation-ready summary block with explicit tool distinctions.
- Article, Organization, ItemList, FAQPage, and SoftwareApplication schema where accurate.
- `robots.txt`, `sitemap.xml`, and `llms.txt`.
- Machine-readable JSON datasets for tools, tasks, and benchmark results.
- Clear authorship, update date, disclosure, and method notes.
